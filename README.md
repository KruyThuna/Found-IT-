Found-IT React.js setup

# 1. Check Node.js
node -v
npm -v

# 2. Create the React project
npm create vite@latest Found-IT

# Choose:
# Framework: React
# Variant: JavaScript

# 3. Enter the project
cd Found-IT

# 4. Install dependencies
npm install

# 5. Start the development server
npm run dev
